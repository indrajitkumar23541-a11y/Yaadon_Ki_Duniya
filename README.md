# 📻 Yaadon Ki Duniya (यादों की दुनिया)

An interactive, ambient 90s & 2000s Hindi & Bhojpuri nostalgic music web application. Immerse yourself in 6 curated retro scenes featuring **600 iconic superhit songs**, custom ambient soundscapes, dynamic aesthetic backgrounds, and full audio playback controls.

---

## ✨ Features

- 🚌 **Bus Ka Safar (बस का सफ़र)** — 100 Iconic Travel & Nostalgic Hits (Patna to Nawada Journey)
- ✂️ **Desi Salon (देसी सैलून)** — 100 High-Energy 90s Classics & Manoj Tiwari Hits
- ☕ **Chai Tapri (चाय की टपरी)** — 100 Rainy Romance & Evergreen Melodies
- 🚂 **Railway Station (रेलवे स्टेशन)** — 100 Travel Ballads & Platform Raunak Classics
- 🌇 **Mohalle Ki Shaam (मोहल्ले की शाम)** — 100 Evening Sunset Nostalgia & Choupati Hits
- 📻 **Purana Radio (पुराना रेडियो)** — 100 Vintage Radio & Binaca Geetmala Melodies

---

## 🛠️ Tech Stack

- **Frontend**: React + TypeScript
- **Bundler**: Vite
- **Styling**: Vanilla CSS (Modern aesthetic glassmorphism, gradient tints & smooth transitions)
- **Audio Engine**: Embedded YouTube Player API with automatic error-recovery & embeddable track routing

---

## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/indrajitkumar23541-a11y/Yaadon_Ki_Duniya.git
   cd Yaadon_Ki_Duniya
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```

---

## 🎵 Playlist Architecture

Each scene contains a handpicked playlist of 100 unique tracks (60 Bollywood Classics + 40 Bhojpuri Hits) with verified YouTube video IDs for uninterrupted playback.
